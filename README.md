# Pudding-releases
## Pudding release downloads
Pudding バイナリ配布用
ダウンロードは以下から

https://github.com/K2san/Pudding-releases/releases/

注意)インストーラー(msi)にコード署名はしていません。ダウンロードして実行すると、WindowsのSmartScreenが「発行元が不明」という警告を出すことがあります。その場合は「詳細情報」→「実行」で進められます。またファイルの真正性はチェックサムで確認できます。
